# Portfolio Website Backend

This is the backend service for my portfolio website.  
It handles contact form submissions and server-side operations using Spring Boot and MySQL.

## Features

- REST API for contact form
- Handles user contact requests
- MySQL database integration
- Backend validation support
- Spring Boot based architecture
- Ready for portfolio and client project integration

## Tech Stack

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven
